# موقع كابتن محمد أسامة

موقع صفحة واحدة (عربي) لمدرب اللياقة كابتن محمد أسامة.

## تعديل البيانات
- **رقم الواتساب واللينكات:** من ملف `config.js`.
- **الصور:** في مجلد `images/` (الأصلية في `images/original/`).
- **خطة التطوير:** في `ROADMAP.md`.
- **النصوص والباقات:** من `index.html`.
- **الألوان:** من أول `styles.css` (المتغيرات في `:root`).

## النشر مجاناً على GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → اختار الفرع والمجلد `/ (root)` → Save.
